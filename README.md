## About

Robo 3T (formerly Robomongo) is a free, lightweight MongoDB management tool for Windows, macOS, and Linux. Features an embedded MongoDB shell for running queries, a visual document editor, collection management, and real-time statistics. Robo 3T's shell-centric approach makes it familiar for developers comfortable with the MongoDB shell, while adding a visual layer on top.

## Common Problems & Limitations

- **MongoDB Only** — Works exclusively with MongoDB; not a general database client
- **Development Status** — Acquired by 3T Software Labs; development trajectory uncertain
- **Studio 3T Competition** — The commercial Studio 3T offers significant additional features
- **Complex Aggregations** — Visual pipeline builder for aggregations requires separate Studio 3T
